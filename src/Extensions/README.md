# Local Bonsai extensions

Bonsai compiles every `*.cs` file here when `src\main.bonsai` loads, as C# 5 (`src\Extensions.csproj` sets `LangVersion` 5): no `$"..."`, `?.`, `nameof`, expression-bodied members or property initialisers. `tests\Extensions.Tests` (MSTest, net472, C# 5) tests them; `scripts\check-workflow.ps1` compiles and runs both. Everything shared between dome workflows lives in lib-open-rigs (see the README's Shared Blocks); only this task's logic is here.

| File | What it holds |
|---|---|
| `TrialLogic.cs` | `Trial` (OpenRigs.Trials' `ConditionedTrial`, the trial log's shared columns, an `IZapitTrial` for its `ZapitTrialCommand`); `TrialRules` (lib-open-rigs' `ITrialRules`, built at Go by `CheckTaskAtGo`: the draw, each trial's timing and laser, and its run along the track: the 50 ms pips, the left spout's licks, the track's end, the outcome); `TrialOutcome` (lib-open-rigs' `TrialOutcome<TrialRow>` with the left valve: the row, its shared block filled by `SharedTrialColumns.Fill`, stamped with its `outcomeTime`, the reward, the penalty at the trial's level, the timeout, and the trial's reward tone level); `TrialDraw` (the task checked by `CheckTask`, as coen-dome-decision-making's: the curriculum, the `trialConditions` it draws with, each built by `BuildConditions` (OpenRigs.Trials `TrialConditions.Build`) into a `BuiltTrialCondition` of `TrialConditionCombination`s (its set and pairs written over the task's text and read back, one task per combination of its list cells and `TaskSchema.ListFields`, a session field of `TaskSchema.SessionFields` refused, at most `TaskSchema.MaxCombinations`; `TaskSchema.Generated.cs` is generated with the schema), the reward zone inside the track's tones (at most 24 kHz), the optogenetics rules (the laser's cap derived from the response window, the trigger hold the Zapit file's max ramp-down); then each trial's draw, its interval, lead, quiet waits, Zapit condition, trial condition by weight (logged as `trialConditionId`, its `trialType` as `trialType`) and its combination (logged as `trialCombinationId`, its row of `Settings_Combinations`, `TrialRules.CombinationsJson`, OpenRigs.Trials `TrialConditions.CombinationsJson`, written at Go), whose values the trial and the rules read: contrast, phase, level, azimuth, track length over wheel gain, cutoff fraction, interval, reward size, quiet waits, zone, lead, laser power and penalty; `TrialRules.MaxStimulusLevel`, `MaxPenaltyLevelDbfs` and `MaxRewardToneLevelDbfs`, OpenRigs.Trials' `MaxSoundLevel.Of`, for the sounds' peak checks); `ReadTask` (the task file read keeping a condition's set values as numbers, OpenRigs.Core `TaskYaml.Read`, so Settings_Task logs them so); `VirtualTrack` (the distance along the track, in wheel cm; rows log track cm); `RunTrials` (lib-open-rigs' `TrialLoop` on the Harp clock, the wheel, both lick detectors (a right-spout lick holds the trial start, as the left's does) and Zapit's replies, its events picked by lib's `PickTrialEvents`) |
| `TrialRow.cs` | `TrialRow`, one `WorkflowData_Trials` row, its fields the columns of `schemas\trial-columns.yml` in order (a test holds them equal) (TaskLogic logs the outcome's `Outcome.Row`) |
| `Sweep.cs` | The tone sweep (`Sweep`, read at Start from `sounds\sweep.json` by `LoadSweep` and checked against rig.yml's rate), the pips laid out on rig.yml's speakers as stored (`sweep.json`'s `pipLevelDbfs`) and checked at Go at the highest level the conditions draw (`PipSet`, made by `LayOutPips`), each pip's buffer at its trial's level (`Sweep.GainOf`) on every speaker or its one (`PipBuffer`) its `WorkflowData_StimulusState` row (`StimulusFrame`, `StimulusStateRow`, `CreateStimulusStateRow`) and what the grating shows (`GratingState`, from each pip and hidden at the outcome by `GratingStates`, the Grating subject) |
| `Curriculum.cs`, `TrialCondition.cs`, `UclOpenCoenDomeNavigationTaskParameters.cs` | The generated classes as lib-open-rigs' interfaces, one small partial class each: OpenRigs.Core `ICurriculum`, OpenRigs.Trials `ITrialCondition` and `IConditionedTask`, which `TrialConditions.Build` and `CurriculumCheck.Problem` read |
| `*.Generated.cs` | Bonsai.Sgen classes for the task file (rig.yml's are OpenRigs.Devices' `OpenRigs.Devices.Rigs`); regenerate with `uv run regenerate-schemas`, never edit |
