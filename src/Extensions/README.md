# Local Bonsai extensions

Bonsai compiles every `*.cs` file here when `src\main.bonsai` loads, as C# 5 (`src\Extensions.csproj` sets `LangVersion` 5): no `$"..."`, `?.`, `nameof`, expression-bodied members or property initialisers. `tests\Extensions.Tests` (MSTest, net472, C# 5) tests them; `scripts\check-workflow.ps1` compiles and runs both. Everything shared between dome workflows lives in lib-open-rigs (see the README's Shared Blocks); only this task's logic is here.

| File | What it holds |
|---|---|
| `TrialLogic.cs` | `Trial` (OpenRigs.Trials' `IZapitTrial`, for its `ZapitTrialCommand`); `TrialRules` (lib-open-rigs' `ITrialRules`, built at Go by `CheckTaskAtGo`: the draw, each trial's timing and laser, and its run along the track: the 50 ms pips, the left spout's licks, the track's end, the outcome); `TrialOutcome` (lib-open-rigs' `TrialOutcome<TrialRow>` with the left valve: the row, its shared block filled by `SharedTrialColumns.Fill`, stamped with its `outcomeTime`, the reward, penalty and timeout); `TrialDraw` (the task checked by `CheckTask`, as coen-dome-decision-making's: the curriculum, the `trialConditions` it draws with, each built by `BuildConditions` into a `TrialConditionDraw` of `TrialConditionCombination`s (its set and pairs over the task's `contrasts` and `auditoryStimulus.amplitude`, the `ConditionFields`), the `Rules` (`ConditionRule`, the schema's x-rules) on the task and every combination, the reward zones inside the sweep, the optogenetics rules; then each trial's draw, its interval, lead, quiet waits, Zapit condition, trial condition by weight (logged as `trialCondition`, its label as `trialType`) and its combination's contrast and amplitude; `Loudest`, a `LoudestSound`, for the pips' peak check); `ReadTask` (the task file read keeping a condition's set values as numbers, `TrialDraw.Read`, so Settings_Task logs them so); `VirtualTrack` (the distance along the track); `RunTrials` (lib-open-rigs' `TrialLoop` on the Harp clock, the wheel, both lick detectors (a right-spout lick holds the trial start, as the left's does) and Zapit's replies, its events picked by lib's `PickTrialEvents`) |
| `TrialRow.cs` | `TrialRow`, one `WorkflowData_Trials` row, its fields the columns of `schemas\trial-columns.yml` in order (a test holds them equal) (TaskLogic logs the outcome's `Outcome.Row`) |
| `Sweep.cs` | The tone sweep (`Sweep`, read at Start from `sounds\sweep.json` by `LoadSweep` and checked against rig.yml's rate), the pips laid out on rig.yml's speakers at amplitude 1 and checked at Go at the loudest amplitude the conditions draw (`PipSet`, made by `LayOutPips`), each pip's buffer at its trial's amplitude (`PipBuffer`) and its `WorkflowData_StimulusState` row (`StimulusFrame`, `StimulusStateRow`, `CreateStimulusStateRow`) |
| `*.Generated.cs` | Bonsai.Sgen classes for the task file (rig.yml's are OpenRigs.Devices' `OpenRigs.Devices.Rigs`); regenerate with `uv run regenerate-schemas`, never edit |
